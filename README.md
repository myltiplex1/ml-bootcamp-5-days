# 🤖 Machine Learning Bootcamp — 5 Days, Hands-on

A complete, practical **5-day introduction to machine learning** for undergraduate (200-level) engineering students.
Every day has **slides** and **Google Colab notebooks** that run in the browser with real, popular datasets.

From your first model to deep learning, computer vision, TinyML on a $5 chip, reinforcement learning and generative AI — all in 15 hours.

## 📅 Course outline

| Day | Topic | What's covered | Notebooks |
|:-:|---|---|:-:|
| **1** | [Introduction to Machine Learning](day1-intro-to-ml/) | What ML is, where it's used, the types of learning (supervised, unsupervised, reinforcement), the ML workflow, a little Python, and a first model on the Iris flowers. | 1 |
| **2** | [From Data to Models](day2-data-to-models/) | NumPy and pandas, exploratory data analysis with seaborn, cleaning, feature engineering, encoding, scaling, and the first supervised models for classification and regression. | 3 |
| **3** | [More Models & Unsupervised Learning](day3-more-models-unsupervised/) | Overfitting, cross-validation, random forests, boosting and SVMs, tuning with GridSearchCV, leak-free pipelines, clustering, PCA, anomaly detection and semi-supervised learning. | 3 |
| **4** | [Deep Learning & Computer Vision](day4-deep-learning-computer-vision/) | Neurons, activations, backpropagation, training curves and dropout; CNNs and transfer learning; object detection, segmentation and pose with YOLO; OpenCV. | 3 |
| **5** | [ML on Devices, Robots & Generative AI](day5-devices-robots-genai/) | Biomedical signals (ECG), TinyML on the ESP32 and Raspberry Pi, robots and reinforcement learning, how language models generate text, and a live computer-vision finale. | 5 |

Each day is 3 hours: short slide blocks alternate with hands-on Colab blocks (the orange **Hands-on** slides tell you when to switch).

## 🚀 Quick start (students)

1. Open a day's folder and click an **Open in Colab** badge.
2. **File → Save a copy in Drive** (so your changes are saved).
3. Run the cells in order with **Shift + Enter**. Exercises are marked ✍️ and the solutions are at the bottom of each notebook.

No installation needed — all you need is a browser and a Google account. Every dataset downloads automatically.

## 📁 Folder layout

Each day folder contains:
```
dayN-.../
├── README.md          what the day covers + Open in Colab buttons
├── colab_notebooks/   Colab notebooks (tested end to end)
└── slides&note/       the slide deck (PDF)
```
(Day 1's notebook folder is called `colab_notebook`.)

## 📊 Datasets

Iris · Titanic · California Housing · Breast Cancer Wisconsin · Mall Customers · Digits · Fashion-MNIST · Imagenette · COCO (pre-trained YOLO) · MIT-BIH Arrhythmia (record 100) · ECG5000 · Gymnasium Taxi · makemore names.
All are public datasets, downloaded from their original or well-known public sources when a notebook runs; credit goes to their creators.
